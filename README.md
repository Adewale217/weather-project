## Weather Website



A modern and responsive weather application built to provide users with real-time weather information for any city around the world.



## Features

- Search weather by city

- Displays current temperature

- Shows weather conditions

- Responsive and user-friendly interface

- Clean and modern design


## Tools Used

- HTML5

- CSS3

- JavaScript

- Python

- Django

- Weather API



## Getting Started

1. Clone the repository

bash

git clone https://github.com/Adewale217/weatherproject.git
